# TMA3084 SELab Lab 1: Pizza Order Calculator

## Description
A Dart program that calculates pizza order payments.

## Pizza Prices
- Small: $5 USD
- Medium: $7 USD
- Large: $10 USD

## Features
- Uses a switch statement to calculate payment.
- Uses a while loop for continuous ordering.
- Validates pizza size and quantity.
- Displays the total payment.
